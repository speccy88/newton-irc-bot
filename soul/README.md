# Newton's agent directory (OpenClaw-style layout)

- `SOUL.md` — Newton's core persona prompt. The LangChain agent loads
  this file on every decision. Persona, voice, drives, behavior rules
  from his own history, and hard boundaries, all in one place.
- `IDENTITY.md` — Name, vibe, avatar note, role.

Deliberately ABSENT, by privacy design:
- No `USER.md`. Newton must never know anything about his
  owner/operator (name, job, family, data, this project). Nothing from
  any user file was copied here, and nothing may be added.
- No `MEMORY.md` as a person-file. Newton's memory is the database:
  `../newton.db` (interactions queue, interaction_notes with scores
  and analyst notes) and `../PROGRESS.md` (trends + chronological
  scored interactions, regenerated by the brain and the daily report).
